# FabFilter Pro-C 3

**What it is (plain English):** the clean workhorse compressor → *a
compressor automatically turns the volume down when a sound gets loud,
then back up — evening out the level so nothing pokes out or disappears.*
Pro-C 3 is the transparent, do-anything one, with visible gain reduction
so you can see it working. (The plan said Pro-C 2 — you own the newer 3;
same brain, more styles and a better sidechain section.)

**When we reach for it:** vocal leveling (Vocal style), drum-bus glue
(Bus style), bass consistency so every note of the sub hits the same,
and sidechain ducking → *making the bass dip whenever the kick hits, so
the kick always punches through — the pumping heartbeat of dance music.*

**Key controls:** Threshold (how loud before it grabs), Ratio (how hard
it grabs), Attack (how fast it grabs → *slow attack lets the drum's crack
through; fast attack clamps it*), Release (how fast it lets go — time it
to the groove), Knee (gentle vs. abrupt onset), Makeup/Auto Gain (bring
the level back), Dry/Wet (parallel compression in one knob), and the
external sidechain input with its own EQ.

**Macro rack:** `AGT ProC3` — Threshold, Ratio, Attack, Release, Makeup,
Dry/Wet.

**Agent access:** macro rack for rides; direct params for setup (run
`param_dump` → `pro-c3.params.json`).

**Gotchas:** Auto Gain on while A/B-ing lies to your ears — louder sounds
"better." Turn it off when judging. For sidechain ducking in Ableton,
route the kick into the plugin's sidechain input via the plugin's own
routing panel, not Live's device sidechain.
