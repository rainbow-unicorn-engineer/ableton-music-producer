# skills — Phase 5 (forever ongoing)

One recipe doc per style, built from dissecting reference tracks together —
e.g. `tape-b-dub-bounce.md`, `ote-texture-beds.md`, `griz-funk-pocket.md`.

Each recipe holds: arrangement math, sound palette (with `find_sounds`
queries once Phase 2 ships), signature techniques, and mix notes — as
concrete Ableton steps.

**The rule that keeps this honest:** the agent automates the mechanical 70%
(setup, sound-finding, MIDI drafts, gain staging); you own the sacred 30%
(what it says, how it feels, when it's done).
